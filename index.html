How this works & what it checks   method · signals · scoring ▸

The method

  • Claude fetches your live page with its web search tool and judges each signal below as pass, partial, or fail, with one line of evidence and one concrete fix.
  • Claude only classifies. The JavaScript maps pass/partial/fail to points, applies each signal's weight, and sums to a 0–100 score, so the number is deterministic and traceable to the checks.
  • It runs from a static page with no backend, so Claude does the fetching (a browser can't fetch arbitrary URLs). Web search must be enabled on your Anthropic account.

What it checks

    Scoring

    • pass = full points, partial = half, fail = zero, each times the signal's weight.
    • Bands: 80–100 AI-ready, 55–79 needs work, 0–54 largely invisible to AI search.
    A readiness heuristic, not a guarantee of citation: AI engines are opaque and change often. It grades the structural fundamentals that reliably help.
